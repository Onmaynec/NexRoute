# Диагностика проблем 🩺

## service.bat не запускается

- распакуйте полный архив из NexRoute Releases, а не Source code ZIP;
- используйте путь без кириллицы и специальных символов;
- откройте свойства скачанного архива и нажмите **Разблокировать**;
- убедитесь, что `bin/winws.exe` и `bin/WinDivert64.sys` присутствуют;
- запустите `service.bat` от имени администратора.

## WinDivert обнаружен антивирусом

WinDivert является легитимным драйвером фильтрации трафика, но относится к инструментам повышенного риска. Проверьте, что архив скачан из официального Release и его SHA-256 совпадает. Не восстанавливайте файлы из неизвестных сборок.

## YouTube не работает

1. Настройте Secure DNS/DoH.
2. Проверьте несколько `general*.bat` стратегий.
3. Временно отключите расширения, влияющие на YouTube.
4. Проверьте `list-google.txt` и пользовательские исключения.
5. Запустите Standard tests и DPI checkers.

## Discord Web работает, Voice не подключается

- обновите hosts через `service.bat`;
- проверьте Discord UDP/Voice fake-payload;
- попробуйте альтернативные стратегии;
- очистите кэш Discord и Discord PTB через Diagnostics;
- проверьте VPN, proxy и приложения, использующие WinDivert.

## Игра или сайт ломается при включённом NexRoute

1. Отключите Game Filter.
2. Установите IPSet Filter в `none`.
3. Добавьте конкретный домен/IP в пользовательское исключение.
4. Не используйте `ipset any` постоянно.

## Служба зависла в STOP_PENDING

- закройте все процессы `winws.exe`;
- удалите другие службы обхода, использующие WinDivert;
- перезагрузите Windows;
- повторно запустите **Remove Services**;
- выполните встроенную диагностику.

## Что приложить к Issue

- NexRoute version;
- Windows 10/11 build;
- точное имя стратегии;
- состояние Game Filter и IPSet Filter;
- релевантные строки Diagnostics;
- ожидаемое и фактическое поведение;
- результат проверки нескольких стратегий.

Не публикуйте приватные домены, IP-адреса локальной сети, токены или полный системный журнал.
