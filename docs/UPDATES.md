# 🔄 Безопасные обновления NexRoute

NexRoute 0.3.1 добавляет встроенный stable-updater для официальных GitHub Releases проекта `Onmaynec/NexRoute`.

## Как это работает

1. Updater запрашивает только последний стабильный GitHub Release.
2. Draft и prerelease-релизы отклоняются.
3. Для версии `X.Y.Z` должны существовать ровно два файла:
   - `NexRoute-X.Y.Z-win-x64.zip`;
   - `NexRoute-X.Y.Z-win-x64.zip.sha256`.
4. SHA-256 из checksum-файла сравнивается с реально загруженным архивом.
5. Архив распаковывается во временную директорию и проверяется до установки:
   - версия внутри пакета совпадает с тегом Release;
   - присутствуют launcher, updater, Service Matrix, upstream lock и patch report;
   - найдено 21 реальная стратегия;
   - patch report содержит 23 отслеживаемых target-а.
6. Перед заменой файлов создаётся полная резервная копия текущей установки.
7. Пользовательские настройки и списки возвращаются поверх нового пакета.
8. Если установка завершается ошибкой, предыдущая версия автоматически восстанавливается.

## Автоматический режим

Автообновление включается через пункт `CHECK UPDATES` в терминальном меню или через `nexroute-update.bat`.

После включения `nexroute.bat` выполняет проверку перед запуском Control Node. По умолчанию повторная проверка выполняется не чаще одного раза в 24 часа. Состояние хранится в:

```text
.service/update-state.json
```

Сетевой сбой или недоступный Release не блокирует запуск NexRoute: updater записывает ошибку в state и продолжает запуск текущей версии.

## Ручной центр обновлений

Запустите:

```text
nexroute-update.bat
```

Доступны действия:

- включить или выключить автоматические обновления;
- немедленно проверить и установить последнюю стабильную версию;
- откатиться к последней резервной копии.

## Что сохраняется при обновлении

Updater сохраняет:

- `.service/language.txt`;
- `.service/services-state.json`;
- `.service/update-state.json`;
- кеш IP-источников;
- локальные backup-файлы;
- `utils/check_updates.enabled`;
- `utils/game_filter.enabled`;
- пользовательские domain/IPSet-файлы из `lists`.

## Резервные копии

Копии создаются рядом с директорией NexRoute:

```text
NexRoute-backups/
```

Хранятся последние четыре backup-набора. Перед rollback дополнительно создаётся safety-копия текущей установки.

## Ограничение доверия

SHA-256 защищает от повреждения архива и несоответствия опубликованному checksum-файлу, но не заменяет цифровую подпись издателя. Updater принимает файлы только из официального release-пути `Onmaynec/NexRoute`.
