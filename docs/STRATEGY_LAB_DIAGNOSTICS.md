# Strategy Lab и диагностика — NexRoute 0.7.1

## Что измеряется

Каждая временно запущенная стратегия проверяется в трёх раундах. Для **рейтинга** учитываются HTTPS-ответы критичных сервисов и контрольных HTTP endpoints. DNS A/AAAA, TLS, ICMP, throughput, HLS и DPI-range хранятся как `diagnosticOnly` — для объяснения, но без повышения балла доступности. Это предотвращает ситуацию, когда успешный DNS скрывает неработающий HTTPS.

При недостаточном числе HTTP-наблюдений или неработающих контролях состояние — `INCONCLUSIVE`; система не выдаёт рекомендацию без доказательств.

## Точность проверок

| Проверка | Что реально подтверждает |
| --- | --- |
| DNS | Есть валидная A или AAAA запись |
| TLS | Рукопожатие с доверенной цепочкой сертификата и правильным hostname |
| HTTPS | Ответ конкретного HTTP endpoint |
| ICMP | Ping, loss и jitter — если ICMP разрешён |
| HLS | Получен реальный сегмент HLS, если manifest URI настроен |
| Throughput | Переданы измеренные байты тестового файла |
| DPI-range | Завершена HTTP-передача. Причина возможного обрыва неизвестна |

DPI-range требует HTTP 200/206 и не менее 32768 байт. Обрыв в 16–20 KiB обозначается `possible-16-20kb-stall` — это гипотеза, а не доказательство вмешательства. HTTP 4xx, timeout и неполная передача не считаются успешными.

Voice readiness Discord/Telegram не выводится из HTTPS/TLS: полноценный UDP/RTP probe не реализован и отмечается как `not-measured`. Старые результаты не переписываются. Новые содержат `measurementModel=https-primary-071`.

## Диагностическая сводка

В Diagnostic Core доступна «Диагностика и рекомендации». Коды `NR-ADMIN-001`, `NR-WD-003`, `NR-RUN-002`, `NR-LIST-004` и `NR-FILTER-005` указывают на наблюдаемый статус и конкретный следующий шаг. Обнаружение дополнительного сетевого фильтра не означает доказанный конфликт.

## Приватный экспорт

Создание ZIP и копирование отчёта используют **allowlist schema 4**, отличный от внутреннего диагностического schema 3. Экспортируются версии компонентов, флаги состояния, агрегированные количества, безопасные коды рекомендаций и сводка последнего Strategy Lab. Сырые журналы, monitor-state, IP, DNS-серверы, SSID, VPN, названия сетевых адаптеров, локальные пути, содержимое user lists, query tokens и сырые ошибки исключаются.

Оригиналы доступны только внутри локального приложения, а не в ZIP/clipboard.
