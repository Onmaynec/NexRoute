# Совместимость 🖥️

## ✅ Поддерживаемые системы

| Платформа | Статус |
|---|---|
| Windows 10 x64 | поддерживается |
| Windows 11 x64 | поддерживается |
| Windows 7/8/8.1 | не поддерживается NexRoute 0.2.0 |
| Windows x86 | не поддерживается |
| Windows ARM64 | не тестировалась |
| Linux/macOS | не поддерживаются этой сборкой |

Для терминального интерфейса требуется Windows PowerShell 5.1 или более новая версия PowerShell.

## 🖥️ Терминалы

| Среда | Статус |
|---|---|
| Windows Terminal | рекомендуется |
| Классический `cmd.exe` | поддерживается через PowerShell renderer |
| PowerShell console host | поддерживается |
| Запуск BAT непосредственно из ZIP | не поддерживается |

RU/EN строки находятся в UTF-8 JSON-файлах и выводятся PowerShell. Сгенерированный `service.bat` не содержит прямой кириллицы и не зависит от OEM-кодовой страницы CMD.

## 🔄 Совместимость со списками Flowseal

NexRoute сохраняет формат и расположение:

```text
lists/list-general-user.txt
lists/list-exclude-user.txt
lists/ipset-exclude-user.txt
lists/ipset-all.txt
```

Версия `0.2.0` создаёт собственные managed-блоки в первых двух файлах. Строки пользователя вне маркеров сохраняются.

## 🌐 Совместимость сервисных профилей

| Категория | Ожидаемое покрытие |
|---|---|
| baseline | встроенные YouTube/Discord сценарии Flowseal |
| web | веб-интерфейс, API и CDN, распознаваемые по доменам |
| experimental | доменное управление без гарантии звонков и медиареле |

FaceTime, Signal, Viber и WhatsApp могут использовать дополнительные UDP-порты и динамические адреса. См. [SERVICES.md](SERVICES.md).

## 📥 Миграция

1. В старой сборке удалите службы через её `service.bat`.
2. Перезагрузите Windows, если WinDivert остался в `STOP_PENDING`.
3. Распакуйте NexRoute `0.2.0` в новую папку.
4. Скопируйте только пользовательские списки.
5. Не переносите старые `service.bat`, `.service` и бинарники.
6. Запустите `service.bat`; матрица создаст состояние по умолчанию.
7. Проверьте сервисные переключатели и повторно установите стратегию.
