# Совместимость 🖥️

## ✅ Поддерживаемые системы

| Платформа | Статус |
|---|---|
| Windows 10 x64 | поддерживается |
| Windows 11 x64 | поддерживается |
| Windows 7/8/8.1 | не поддерживается NexRoute 0.1.1 |
| Windows x86 | не поддерживается |
| Windows ARM64 | не тестировалась |
| Linux/macOS | не поддерживаются этой сборкой |

Для терминального интерфейса требуется Windows PowerShell 5.1 или более новая версия PowerShell.

## 🖥️ Терминалы

| Среда | Статус |
|---|---|
| Windows Terminal | рекомендуется |
| Классический `cmd.exe` | поддерживается |
| PowerShell console host | поддерживается |
| Запуск BAT непосредственно из ZIP | не поддерживается |

Renderer использует ASCII-safe PowerShell source и явно декодирует русский текст как UTF-8. Сгенерированный `service.bat` не содержит прямой кириллицы, поэтому интерфейс не зависит от OEM-кодовой страницы CMD.

## 🔄 Совместимость со списками Flowseal

NexRoute сохраняет формат и расположение пользовательских файлов Flowseal:

```text
lists/list-general-user.txt
lists/list-exclude-user.txt
lists/ipset-exclude-user.txt
lists/ipset-all.txt
```

Поддомены в доменных списках обрабатываются по правилам upstream `winws`/hostlist.

## 📥 Миграция

1. В старой сборке откройте `service.bat` и удалите службы.
2. Перезагрузите Windows, если WinDivert остался в состоянии `STOP_PENDING`.
3. Распакуйте NexRoute в новую папку.
4. Скопируйте только пользовательские списки; не переносите старые бинарники и системные `.bat`.
5. Запустите диагностику.
6. Повторно протестируйте стратегии и установите рабочую службу.

При обновлении с `0.1.0` не копируйте старый `service.bat`: интерфейс `0.1.1` требует новый `.service/nexroute-ui.ps1` и обновлённый BAT-router.

## ⚠️ Возможные конфликты

- GoodbyeDPI и другие инструменты на WinDivert;
- AdGuard и системные фильтры;
- Killer/SmartByte/Intel Connectivity Network Service;
- VPN-клиенты и корпоративные endpoint-фильтры;
- антивирусный карантин WinDivert;
- нестандартные системные proxy/DNS-настройки.

Используйте встроенную диагностику перед созданием Issue.
