# NexRoute 0.6.5 — критерии готовности релиза

Этот документ фиксирует обязательные проверки для 0.6.5. Релиз считается готовым только после прохождения автоматических source/package gates и проверки нового классического интерфейса.

## Интерфейс

- [ ] основной интерфейс использует числовую навигацию в стиле 0.2.2;
- [ ] выход/возврат отображается как `[00]`;
- [ ] используется новый шестистрочный ASCII-логотип NEXROUTE;
- [ ] логотип выводится одним цветом;
- [ ] фон остаётся чёрным, основной акцент — красным;
- [ ] успешные состояния — зелёные, предупреждения — жёлтые, ошибки — красные;
- [ ] основной пункт `[12] Strategy Lab` открывает новый сценарий тестирования напрямую;
- [ ] функции 0.6.4 остаются доступными через classic menu/advanced toolkit.

## Strategy Lab

Обязательный автоматизированный контракт:

- [ ] classic module загружается после Strategy Lab v2 и является финальным runtime override;
- [ ] можно запустить все стратегии или выбранный набор;
- [ ] перед тестированием выполняется preflight;
- [ ] каждая стратегия получает повторные раунды измерений;
- [ ] присутствуют DNS, TLS, HTTPS, ICMP, throughput, media и DPI range probes;
- [ ] control targets используются отдельно от критических сервисов;
- [ ] выводятся живые `OK/WARN/FAIL/SKIP` состояния и прогресс;
- [ ] сохраняются JSON и CSV history;
- [ ] explainable ranking 0.6.4 остаётся совместимым;
- [ ] при недостатке данных используется `INCONCLUSIVE`;
- [ ] исходная установленная стратегия восстанавливается после лаборатории.

## Ограничения

CI подтверждает целостность пакета, runtime contract и воспроизводимость сборки. Он не доказывает, что одна конкретная DPI-стратегия будет одинаково работать у всех провайдеров. Результаты Strategy Lab относятся к сети и моменту, в которых они были измерены.
