# Политика безопасности 🔐

## Поддерживаемые версии

| Версия | Статус |
|---|---|
| 0.1.x | поддерживается после первого стабильного релиза |
| development branches | без гарантий стабильности |

## Приватное сообщение о проблеме

Не публикуйте приватные данные или чувствительные диагностические журналы в открытом Issue.

Используйте GitHub Security Advisories репозитория. В отчёте укажите:

- затронутую версию NexRoute;
- версию Windows;
- компонент (`service.bat`, build script, updater или release archive);
- последовательность воспроизведения;
- ожидаемое и фактическое поведение;
- возможное влияние;
- предлагаемый вариант исправления, если он известен.

## Проверка релиза

1. Скачивайте NexRoute только из официального раздела Releases.
2. Проверяйте SHA-256 архива.
3. Не запускайте архивы из неофициальных каналов и зеркал.
4. Проверяйте `NEXROUTE_BUILD_INFO.txt` и `THIRD_PARTY_NOTICES.md`.
5. Помните, что SHA-256 подтверждает целостность опубликованного файла, но не заменяет цифровую подпись исполняемых компонентов.

## Модель доверия

NexRoute запускается с правами администратора, управляет Windows-службами и загружает WinDivert driver. Ошибка или подмена файлов может иметь системные последствия. Release pipeline поэтому:

- получает asset только из официального Flowseal GitHub Release;
- фиксирует upstream version;
- проверяет обязательную структуру архива;
- не хранит бинарники в Git;
- публикует checksum итогового ZIP;
- сохраняет сторонние уведомления.
